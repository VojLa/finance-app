# Finance App user documentation

This directory is reserved for end-user guidance. It should explain how to use
features and interpret values without exposing internal API, persistence,
security, or implementation detail.

Initial user guides will be added per released feature under `getting-started/`,
`accounts/`, `imports/`, `investments/`, `portfolio/`, `troubleshooting/`, and
`faq/`. Do not infer user-facing behavior from planned work; document only
implemented, accepted behavior.
