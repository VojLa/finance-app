# Reading workflow

1. Read `AGENTS.md` and `memory/codex_rules.md`.
2. Select one project map from this directory.
3. Select one [domain map](../domain-map/README.md).
4. Open the linked domain README.
5. Load only the relevant invariant, flow, code and test files.

Use generated inventories for exhaustive discovery. Do not scan the whole
repository when a domain map already identifies the owner.
