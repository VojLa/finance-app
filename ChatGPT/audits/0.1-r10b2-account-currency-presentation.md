## Evidence ownership

The authorized multi-account read keeps two immutable outputs:

1. `portfolio`, built only from manifest-selected primary snapshots in
   `User.baseCurrency`; and
2. `account_presentations`, built from the exact companion snapshot in
   `Account.currency`, or the same primary identity when both currencies are
   equal.

Both selections occur in one `REPEATABLE READ` transaction. Companion
validation requires the same account metadata, timestamp, granularity, source,
calculation version, native breakdowns, and item lineage. Missing, duplicate,
wrong-version, or corrupt evidence returns the existing safe 409 error. No
read-time FX, provider call, refresh, latest lookup, or reconstruction exists.

## Public contract

Top-level portfolio currency and summary remain primary. Each nested account
now exposes:

- `snapshotId`: presentation snapshot identity;
- `primarySnapshotId`: refresh-manifest primary identity;
- `currency`: explicit account presentation currency;
- companion summary and companion positions.

`aggregatePositions` is an explicit primary-currency collection for the
portfolio "all accounts" view. Dashboard global summary, allocation, and top
positions continue consuming primary positions; only account cards consume
presentations. Internal rate IDs, pivot roles, provider metadata, and market
requirements are not public.

## Browser boundary
