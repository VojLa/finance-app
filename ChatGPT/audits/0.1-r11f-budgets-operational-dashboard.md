## Boundary findings

- Budget reads and writes are implemented in FastAPI/SQLAlchemy and enforce
  principal-owned category and account visibility.
- Monthly saves are serialized and replace child state atomically.
- Operational dashboard reads use persisted transaction CZK reporting evidence.
  They do not call market providers, create exchange-rate evidence, recalculate
  snapshots, or write finance rows.
- MONEY and percentage values cross the Python/TypeScript boundary as exact
  decimal strings. Conversion to JavaScript numbers is restricted to the UI
  presentation model.
- Financial snapshot state and operational dashboard state remain separate; the
  operational response contains no financial-summary or account-balance
  fallback.
- The active budget and operational dashboard routes contain no Prisma access or
  TypeScript domain calculation.
