## Findings and remediation

The original production TypeScript paths imported Prisma and bcrypt directly. They
were replaced by a server-only generated-contract adapter over three FastAPI use
cases. NextAuth now retains only JWT session ownership. Registration has a dedicated
short-lived service identity; password change uses the current persisted user and
does not accept caller-selected identity fields.

Python normalizes emails, trims optional names, hashes new passwords with bcrypt cost
12, caps passwords at bcrypt's 72 UTF-8 byte boundary, and accepts an existing hash
created by bcryptjs. Missing users and wrong passwords share one error and one bcrypt
comparison path. Duplicate email writes are closed by both lookup and database unique
constraint handling.

The general HTTP audit log contains request ID, method, route, response status and
duration only. It does not log request bodies, email, password, hashes, Authorization,
or Cookie. ADR 0007 records the credential contract and makes shared rate limiting a
release blocker before public or multi-user deployment; a misleading process-local
limiter was not added to the current personal deployment.
